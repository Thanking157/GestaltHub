## 關於 GestaltHub
GestaltHub 是我製作的一款免費、開源的 iOS / iPadOS MobileGestalt 修改工具！
希望把各種 MobileGestalt Key 和裝置功能設定集中在同一個 App，讓大家不用再東載西載，就能更方便地修改和管理自己的裝置 :D
目標是讓 MobileGestalt 修改變得更簡單、更方便 w

## ✨ 功能
- 📱 **MobileGestalt Key 管理** — 查看、修改及管理各種 MobileGestalt Key。
- 🏝️ **動態島 / AOD** — 調整動態島、永遠顯示及相關顯示功能。
- 🖥️ **iPadOS UI / Stage Manager** — 修改 iPadOS 介面及多工處理相關設定。
- 🤖 **Apple Intelligence** — 管理 Apple Intelligence 與相關系統功能 Key。
- 🌎 **地區與系統設定** — 修改裝置地區、機型資訊及系統相關設定。
- 💾 **自動備份與還原** — 修改前自動備份，並提供備份管理與還原功能。
- 📋 **Logs** — 查看操作紀錄及修改狀態。
部分功能屬於實驗性功能，實際效果可能依裝置型號及 iOS / iPadOS 版本而異。

## 📲 安裝
GestaltHub 提供未簽署的 IPA，需要使用自己的簽名工具重新簽署後才能安裝！

**下載方式：**
前往 [GitHub Releases](https://github.com/Thanking157/GestaltHub/releases)，下載 `GestaltHub-unsigned.ipa`。
下載完成後，使用自己習慣的 IPA 簽名工具重新簽署並安裝即可 :D
**注意：** 安裝成功不代表所有功能都能正常使用，部分 MobileGestalt 修改需要特定系統版本及存取權限。
