# GestaltHub

GestaltHub 是一個面向 iOS 與 iPadOS 的 MobileGestalt 管理工具，讓你可以用較直覺的方式查看、暫存與套用 MobileGestalt 設定。

## 功能

- 📱 裝置資訊：查看目前裝置與系統版本
- 🧩 MobileGestalt：依分類瀏覽與搜尋 Key
- ✨ 顯示功能：動態島、AOD、壁紙視差、HDR 等
- 📲 iPad 功能：iPad UI、Stage Manager 與多工相關設定
- 🤖 Apple 智慧功能：Apple Intelligence、Siri 等相關 Key
- 🌏 地區與系統設定：地區、相機、音訊及其他系統 Key
- 💾 自動備份：套用修改前保存 MobileGestalt 備份
- 🔄 驗證與還原：寫入後驗證，並提供備份還原
- 📋 Logs：查看讀取、修改、套用與錯誤紀錄
- ⚠️ 實驗功能警告：對高風險或實驗性 Key 顯示提醒

目前 KeyCatalog 已整理多個 MobileGestalt 功能與 Key，並標示分類、支援系統、值類型與風險等資訊。

## 使用方式

1. 讀取裝置 MobileGestalt
2. 選擇要修改的功能
3. 暫存修改
4. 套用前自動建立備份
5. 寫入後重新讀取並驗證
6. 如有需要，可以從「備份」頁面還原

App 主要分成「首頁」、「MobileGestalt」、「備份」與「設定」四個區域。

## 風險提醒

MobileGestalt 修改可能依裝置、iOS/iPadOS 版本與系統權限而有不同結果。部分功能被標記為實驗性或需要特定條件；請先建立備份，再進行修改。

GestaltHub 不保證所有 Key 在所有裝置或系統版本上都能正常運作。
