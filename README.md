## 功能
- 📱 MobileGestalt Key 管理
- 🏝️ 動態島 / AOD
- 🖥️ iPadOS UI / Stage Manager 相關功能
- 🤖 Apple Intelligence 相關 Key
- 🌎 地區與系統相關設定
- 💾 自動備份與還原
- 📋 Logs

## 注意
這是我第一次製作這類 App XD
初版可能還存在一些 Bug 或不穩定情況請見諒@@;
如果遇到任何問題或 Bug歡迎回報給我我會盡快確認並修復:D!
部分功能屬於實驗性功能實際結果可能依裝置與系統而異w
此版本提供 Unsigned IPA需要自己簽名安裝:D

## 安裝
下載 Release 中的 `GestaltHub-unsigned.ipa`，  
使用自己的簽名工具重新簽名後即可安裝w
